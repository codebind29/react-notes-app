# 📝 React Notes App

A simple and responsive Notes App built using **React.js** and **Tailwind CSS**.

The application allows users to create and delete notes through a clean and modern interface.

## 🚀 Features

- Add new notes
- Delete notes
- Dynamic note counter
- Controlled form inputs
- Responsive layout
- Modern dark-themed UI
- Clean and simple note cards

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite

## 🧠 Concepts Practiced

- React Components
- `useState` Hook
- State Management
- Form Handling
- Event Handling
- Array Methods
- `map()` for dynamic rendering
- Responsive design with Tailwind CSS
